GCDM — Cooldown Manager skin for World of Warcraft Retail.

Clean layout control for Blizzard’s Cooldown Viewer: Essential, Utility, buff icons, and buff bars. Tune sizes, spacing, borders, fonts, keybind labels, press feedback, power bar, glow, and combat-safe aura sounds — without replacing Blizzard’s cooldown logic.

Open with /gcdm. Profiles can be exported and shared. Built for Interface 120100 (Midnight / 12.1).
